=======================================================
 SAR OCEAN WIND FIELD ESTIMATION API - LOCAL SETUP GUIDE
=======================================================

This guide provides step-by-step instructions for setting up the Python environment, downloading the required deep learning weights, authenticating with Google Earth Engine, and launching the local FastAPI server.

-------------------------------------------------------
 PHASE 1: REPOSITORY PREPARATION & MODEL WEIGHTS
-------------------------------------------------------
1. Clone or download this repository to your local machine.

2. DOWNLOAD THE DEEP LEARNING WEIGHTS (.pth)
   This API relies on a custom-trained ResNet-50 computer vision model to extract wind direction. 
   Because the pre-trained weights file (`best_resnet50_direction_model.pth`) is approximately 95MB, 
   it exceeds standard GitHub hosting limits and must be downloaded separately.

   Download the weights file here: 
   https://drive.google.com/file/d/14t7T5Ai5DlYvDYWJwVGHPNXDdsyeSfOH/view?usp=sharing

3. Place the downloaded `best_resnet50_direction_model.pth` file directly into the root 
   folder of this project (it must be in the exact same folder as `main.py` and `wind_model.py`).

-------------------------------------------------------
 PHASE 2: PYTHON VIRTUAL ENVIRONMENT & LIBRARIES
-------------------------------------------------------
1. Open your terminal (PowerShell, Command Prompt, or Bash).

2. Navigate to the project directory
   
3. Create a clean Python Virtual Environment:
   python -m venv venv
   
4. Activate the Virtual Environment:
   - Windows (PowerShell): .\venv\Scripts\Activate.ps1
   - Windows (CMD): .\venv\Scripts\activate.bat
   - Mac/Linux: source venv/bin/activate
   
5. Install all required dependencies from the requirements file:
   pip install -r requirements.txt

-------------------------------------------------------
 PHASE 3: GOOGLE EARTH ENGINE AUTHENTICATION
-------------------------------------------------------
This API natively queries the Google Earth Engine (GEE) cloud to pull live Sentinel-1 SAR imagery. 
Your local machine must be authenticated to access the COPERNICUS/S1_GRD datasets.

1. Ensure your terminal is still in the active virtual environment.
2. Run the Earth Engine authentication command:
   earthengine authenticate
3. A browser window will open. Log into your G-Suite account (ensure it is registered with Google Earth Engine).
4. Click "Allow" or "Generate Token".
5. If it gives you an authorization code, copy it and paste it back into your terminal. 
   (Some modern systems will complete the authentication automatically).

-------------------------------------------------------
 PHASE 4: LAUNCHING THE FASTAPI SERVER
-------------------------------------------------------
1. With your virtual environment activated, start the Uvicorn ASGI server:
   uvicorn main:app --reload
   
2. If successful, your terminal will display:
   "Uvicorn running on http://127.0.0.1:8000"
   
3. Open a web browser and go to:
   http://127.0.0.1:8000/docs
   
4. You will see the interactive OpenAPI Swagger documentation. You can now test the 
   /api/v1/wind-field and /api/v1/wind-map endpoints directly from your browser!

-------------------------------------------------------
 SHUTTING DOWN
-------------------------------------------------------
- To stop the server, press CTRL + C in your terminal.
- To exit the virtual environment, type: deactivate
